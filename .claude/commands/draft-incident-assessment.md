description: Draft the assessment notes for a suspected data breach: facts on record, the clocks, the questions to answer.

Read CLAUDE.md. Run npm run security -- draft-incident-assessment <incident>. Use --json when you need to work further with the rows. Never invent a record, a date or a control status that is not in the records.

The draft goes to drafts/. Never notify a regulator or a person from here. When the assessment is done, record assessed_on and serious_harm with /update.
